# Zenvy
Zenvy is a streetwear brand built for expression, individuality, and urban culture.

Project Overview
Zenvy is a modern, responsive e-commerce web interface developed as a final project for Web Technology. The website showcases a minimalist online store featuring curated products with a clean and user-friendly design.
The goal of this project is to apply front-end web development skills using HTML, CSS, and JavaScript while following best practices in UI/UX design, responsiveness, and accessibility.

Project Goals
* Create a visually appealing and modern web interface
* Implement responsive design for mobile, tablet, and desktop
* Ensure clean, structured, and semantic code
* Apply proper layout techniques using CSS Grid and Flexbox

* Technologies Used
* **HTML5** – Structure and semantic layout
* **CSS3** – Styling, layout (Flexbox & Grid), responsiveness
* **JavaScript – Interactivity and cart functionality
* **GitHub** – Version control and project hosting

Features
*  Product listing with images, descriptions, and prices
*  Add to Cart system with dynamic updates
*  Cart modal showing selected items and total price
*  Buy Now button with confirmation alert
*  Fully responsive design (mobile, tablet, desktop)
*  Mobile-friendly navigation menu

Responsiveness
The website follows a **mobile-first approach**:
* **Mobile:** Single-column layout
* **Tablet:** Two-column layout
* **Desktop:** Multi-column product grid
* Navigation adapts with a hamburger menu on smaller screens

How to Run the Project Locally
1. Download or clone the repository:
   ```bash
   git clone https://github.com/yourusername/zenvy.git
   ```

2. Open the project folder:
   ```bash
   cd zenvy
   ```
3. Open `index.html` in your browser:

   * Double-click the file
   * OR right-click → Open with browser
